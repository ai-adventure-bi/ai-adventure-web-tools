# Add a shared character library

Put full-body T-pose images in this folder. Filenames can be anything. Then run `./make-library-index.ps1` from the project folder; it lists every supported image automatically in `library.json`.

The site will load those images when served from a web server. If you simply open `index.html` from disk, use the **Add character pictures** button instead; uploaded pictures are retained in that browser's local storage.
