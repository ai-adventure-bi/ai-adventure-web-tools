How does the Game of Life work?

Imagine every square is a tiny creature. Each creature looks at the 8 squares around it. Then, all at once, every square decides whether it will be alive in the next turn.
😢

Too lonely

If a live cell has fewer than 2 neighbours, it dies because it is too lonely.

😊

Just right

If a live cell has 2 or 3 neighbours, it stays alive for the next turn.

😵

Too crowded

If a live cell has more than 3 neighbours, it dies because things are too crowded.

🐣

A new cell appears!

If an empty square has exactly 3 live neighbours, a brand-new cell is born there.

These cells only follow these tiny rules — but together they can create moving shapes, repeating patterns, and even machines that build more patterns. That is called emergence: simple rules creating surprisingly complicated behaviour.
